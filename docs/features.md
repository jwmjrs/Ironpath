# Ironpath feature guide

Ironpath is designed to be a companion: useful during a play session, but never a replacement for deciding how your group wants to play.

## Overview

The landing page explains Ironpath, shows whether a group is connected, and gives fast access to group lookup or the progression roadmap. Choose **Unsync group** to clear the currently connected group from the browser.

## Dashboard

The Dashboard is the group-facing centre of Ironpath.

| Feature | What it does | Example |
| --- | --- | --- |
| Group lookup | Searches the public Group Ironman roster and refreshes member data. | Enter the group’s exact name after a session. |
| Member standings | Compares public Hiscores totals, skill leaders, and rank markers. | See who is nearest to the group’s next skill goal. |
| View as | Sets the selected member on relevant pages. | Pick your account so Farming, Familiars, and access checks use your levels. |
| Adventurer’s Log | Displays compact, recent public activity by member. | Review level-ups and milestones after the group logs in. |
| Group item history | Keeps a searchable group-wide drop and item archive. | Search for a pet to see who got it and when. |
| Drop archive key | Lets members opt in to sharing only item-history archive data. | Copy the key on one device and join the archive on another. |

Public activity is a useful snapshot, not a complete real-time account audit. See [Data sources and limitations](data-sources.md) for details.

## Distractions and Diversions

This is a routine tracker for daily, weekly, and monthly RuneScape activities.

- Click the **circle** beside an activity to mark only that task complete.
- Hover or focus the task name for a practical information card. For example, Meg’s guidance explains why dialogue choices matter.
- Use **Sync quest access** to compare known quest completion with activity requirements.
- Toggle **Show available only** to hide activities the selected character cannot currently access.
- Checking tasks changes local routine state only; it does not alter a RuneScape account.

## Task Generator

Use this when the group wants a sensible Ironman objective but does not know what to do next. Suggestions are written as concrete, playable tasks rather than vague prompts and use the selected character where possible.

For example, Ironpath aims to suggest a specific level, unlock, or supply objective that supports progression—not a generic instruction such as “prepare for a quest.”

## Supplemental Info

Open **Supplemental Info** for focused planning references.

| Page | Use it for |
| --- | --- |
| Farming Routes | Checkable herb, tree, and fruit-tree circuits with travel suggestions, crop recommendations, and separate reset buttons. |
| Shop Runs | Ironman-oriented stock reminders for useful shop stops. |
| Invention | Searchable component notes: practical perk uses, what to save while training, and common sources. |
| Familiars | Available Summoning familiars with compact charm, tertiary, and pouch-recipe details. |
| Archaeology Collections | Collectors, artefacts, first-completion rewards, and personal check-off lists. |
| Dungeon Tools | Dungeoneering potion herbs and secondaries, pouch recipes, and floor-theme boss references. |

### Farming Routes example

Choose **Herb run**, check every patch after visiting it, then use **Clear herb checks** when it is time for a new herb cycle. Tree and fruit-tree checks are kept separately because their timers are different.

### Dungeon Tools example

Open a floor theme, choose a boss, and Ironpath opens a Wiki-backed encounter card with an image, mechanics summary, and a link to the full reference.

The Archaeology and Dungeon pages are marked as test features because their live reference data can change as external sources evolve.

## Desktop companion

The macOS and Windows desktop launchers are intentionally small. They open the official Ironpath website, so normal site updates reach users without a new installer. A new installer is only needed when the launcher itself gains a major native feature.
