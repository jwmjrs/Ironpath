# Ironpath brand reference

Use this identity for all new Ironpath logos, reference graphics, headers, promotional images, and app icons.

## Identity

A Zaros-inspired circle and equal-armed cross with a central path motif. Lavender/amethyst silver with ice-blue highlights, against near-black surfaces. Preserve the recognizable four cardinal points and avoid the retired red compass identity.

- Primary emblem: `public/ironpath-zaros-mark.png`
- Horizontal brand lockup: `public/ironpath-zaros-wordmark.png`
- Web/app icons: `public/ironpath-zaros-192.png` and `public/ironpath-zaros-512.png`
- Desktop packaging icons: `desktop/icons/ironpath.png`, `ironpath.ico`, and `ironpath.icns`

Center the combined Ironpath emblem and name on every page, including the entry page and About/FAQ/Privacy reference pages. Keep navigation centered beneath the shared header branding.

Use the illustrated horizontal lockup for all page headers and landing-page branding, including compact navigation, About/FAQ, and future reference graphics. Use `app/brand-logo.tsx` for headers with a subtitle. Keep the image proportional and give it accessible Ironpath alternative text. The logo lettering stays independent of the selected interface font. The PNGs retain transparency. Historical brand assets remain in the repository for recovery but should not be used in new work. Existing installers retain their packaged icons until rebuilt.

## Palette and meaning

| Role | Color |
|---|---|
| Background | #07080a |
| Panel | #111216 |
| Secondary panel | #0c0d10 |
| Body text | #f2f3f5 |
| Quiet subtext | #9b9faa |
| Links / ingredients / reference labels | #87dce0 |
| Brand / selected navigation | #b8a3f7 |
| Primary action fill | #7556c2 |

Keep success, caution, and error colors meaningful. Do not recolor in-game items, charm types, or status indicators merely to match the brand; reference images must depict the correct object. Never put an Ironpath emblem in a missing item-image slot. Use an appropriate fallback icon with an unavailable-image description.

## Asset generation record

Created using the built-in image-generation tool; no API key or fallback CLI was used. Icon formats and standard web sizes are conversions of the approved emblem, not independently designed variants.

### Emblem prompt

Use case: logo-brand. Asset type: a new primary Ironpath app emblem for a modern very dark RuneScape 3 Group Ironman companion. Design a sleek Zaros-inspired insignia: a precisely symmetric equal-armed cross inside a circular ring with four short cardinal projections, evoking the Zaros sigil, integrated with a subtle forward path cut into its center. A single unified simple emblem, no shield, no compass needle, no sword, no characters. Cool luminous pale lavender and amethyst silver with a restrained ice-blue edge accent, graphite negative space. Modern premium fantasy identity with crisp geometric silhouette and very subtle beveling, readable at 32px, not elaborate illustration. Composition: square, centered emblem occupying about 78% of canvas, generous clear margin. Genuinely transparent background; no backdrop, no glow cloud, no floor, no text, no wordmark, no watermark. Preserve clean alpha edges. This is original fan companion branding inspired by Zaros, not an official RuneScape logo.

### Horizontal lockup prompt

Use case: logo-brand. Asset type: horizontal Ironpath brand lockup for website reference pages and future brand graphics. Input image is the established new Ironpath Zaros-inspired emblem: preserve that exact emblem's shape and colors. Place it to the left of the exact word 'IRONPATH' (I R O N P A T H), with generous space between emblem and wordmark. Crisp modern geometric uppercase sans-serif lettering, pale silver-lavender, medium-heavy weight and subtle tracking. No subtitle, no extra text. Emblem height about equal to 1.4 times letter height. Very wide centered horizontal composition with safe margins, approximately 3:1. Elegant minimal premium gaming companion identity for very dark backgrounds. Genuinely transparent background. No panel, no scenery, no floor, no glow cloud, no additional symbols or red coloring. Clean alpha edges.
