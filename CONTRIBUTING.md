# Contributing to Ironpath

Thanks for helping make Ironpath more useful for RS3 Group Ironman groups.

## Good contributions

- Corrections to Ironman-specific information.
- Clearer task wording and practical route improvements.
- Reliable handling for public RuneScape data.
- Accessibility, mobile layout, and readability improvements.
- Additional repeatables, familiars, invention components, shops, and routes with verifiable sources.

## Before opening a change

1. Search existing issues and discussions.
2. Keep each change focused on one improvement.
3. Explain any source material used for RuneScape-specific information.
4. Avoid including personal account data, access keys, or local database files.
5. Run a production build before requesting review.

## Style

- Prefer clear, direct copy over jargon.
- Preserve the app's responsive behavior.
- Add graceful empty and error states for any new external data source.
- Do not describe the project as official RuneScape or Jagex software.
