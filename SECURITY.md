# Security policy

## Reporting a vulnerability

Please do not publish potential security issues in a public issue tracker. Contact the project maintainer privately with:

- A clear description of the issue.
- Steps to reproduce it.
- The potential impact.
- Any suggested mitigation, if available.

Avoid including sensitive account information, access keys, workspace tokens, or personally identifying data in the report.

## Scope

Issues involving workspace access, server-side data handling, external requests, authentication boundaries, or deployed infrastructure are in scope for responsible disclosure.
