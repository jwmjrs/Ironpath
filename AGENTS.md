# Ironpath project guidance

Before changing visual styling or creating Ironpath-branded images, read `docs/BRAND.md`.

Center the Ironpath logo and name as one unit on all pages, including the entry and About pages.

Use the current Zaros-inspired emblem and wordmark for headers, reference-page branding, and future promotional graphics. Preserve the near-black surfaces, teal reference text, and violet brand/action palette. Keep warning, error, success, and in-game charm colors meaningful.

External game reference images should depict the correct item, character, or location. Use `app/reference-image.tsx` for recovery and accessible fallbacks; do not replace missing game images with the Ironpath logo. Image-title redirects must be preserved when matching Wiki responses to requested subjects.
